# VibeShield

Web bilingüe (ES / EN) para agencia de rescate y blindaje de aplicaciones *vibe-coded* (Next.js, Supabase, Firebase, Flutter).

## Scripts

```bash
npm run dev        # Servidor local de desarrollo
npm run typecheck  # Verificación TypeScript strict
npm run lint       # ESLint
npm run test       # Suite completa Vitest
npm run build      # Build de producción (Vercel / estático)
```

## Configuración

Copia `.env.example` a `.env.local` para personalizar correo de contacto, URL pública o enlace de agenda (Cal.com / Calendly).
